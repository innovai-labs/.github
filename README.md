# .github

This repository contains shared, organization-wide GitHub defaults for **Innovai Labs**, a small software studio.

Website: [innovailabs.com](https://innovailabs.com)

## What this `.github` repository can configure

GitHub uses this special repository to manage defaults and community files across repositories in the organization, including:

- Organization profile content (`/profile/README.md`)
- Issue templates and `config.yml` (`/.github/ISSUE_TEMPLATE/`)
- Pull request templates (`/.github/pull_request_template.md`)
- Community health files such as `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SECURITY.md`

See `/profile/README.md` for the public organization profile content.
